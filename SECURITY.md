# Security policy

## Supported versions

DiskClearance has not released v1.0. No version is currently supported for production use or trusted with irreplaceable files.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a public issue for path-validation bypasses, unintended deletion, privilege escalation, permission leakage, symlink races, or other security-sensitive defects.

Include the affected commit, operating system version, reproduction steps using disposable test data, and expected versus observed behavior. Never include secrets or another person's data.
