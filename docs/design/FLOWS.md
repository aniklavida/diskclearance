# Product flows

## First run

Welcome → Scan Mac → request only required permission → stream verified results → Ready to clear / Needs your review / Protected → review plan → Move to Trash or Delete Now → completion.

## Safe action

Select findings → inspect evidence → build immutable plan → show recoverability and totals → confirm → revalidate each target → execute per item → store outcomes → show reclaimed versus pending-in-Trash space.

## Permission recovery

Encounter inaccessible area → retain partial results → explain missing coverage → open the relevant System Settings location → retry only that scope → merge newly verified results.

## Restore

Open History → choose eligible Trash operation → verify exact trashed item and destination → resolve conflicts without overwrite → restore → record outcome.

Permanent deletion never enters the restore flow.
